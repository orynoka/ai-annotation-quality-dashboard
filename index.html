使用说明

第一次使用，从这里开始
● 数据默认留在本机
1启动服务

双击“启动看板.cmd”，浏览器会打开本地地址。

2上传CSV

选择当天文件，同日期可覆盖或合并，最多保留14天。

3生成分析

填写DeepSeek API Key，模型读取脱敏统计摘要。

4推送飞书

复用已登录的飞书CLI，创建新文档或追加旧文档。

CSV必须包含哪些字段？

日期、项目名称、标注员姓名、组别/负责人、任务类型、任务难度、完成量、有效量、质量得分、作业时长。缺少字段时页面会明确提示。

怎样理解几个核心指标？

完成人效＝总完成量÷总工时，表示每小时完成多少条；有效率＝总有效量÷总完成量，表示真正可用结果的比例；质量得分是抽检结果；风险等级是规则命中后的最高风险。

7天和14天数据从哪里来？

每次上传带不同日期的CSV，系统会把当天数据保存到本机data目录。数据不足7天时按实际天数显示，不会补造数据；同一天再次上传会让你选择覆盖或合并。

哪些内容会发送给DeepSeek？

只发送汇总指标、风险分布、组别和任务统计，以及脱敏后的重点人员摘要。API Key只保存在当前页面内存，刷新页面后需要重新填写。

飞书推送如何工作？

看板通过本地服务调用已经登录的lark-cli。创建模式会生成新文档；追加模式只写到目标文档末尾，不覆盖原内容。只有点击推送按钮时才会产生真实外部写入。

常见问题

“本地服务未启动”：请双击启动脚本；“DeepSeek连接失败”：检查API Key、网络和模型名称；“飞书需要刷新”：再次检查连接，CLI会自动刷新用户令牌；“暂无趋势”：至少上传两个不同日期的数据。
